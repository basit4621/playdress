# PLAY DRESS UP 👗✨
> **Modest Fashion & Digital Twin Styling Platform**

PLAY DRESS UP is an interactive fashion-tech web platform where users create a personalized digital avatar that mirrors their real-world body shape and skin tone, style modest and elegant outfits for themed daily challenges, earn reward coins, and explore direct doorstep shopping from curated boutiques.

---

## 🌟 Key Features (Phase 1 Prototype)

### 1. Dynamic SVG Avatar Customizer (Digital Twin)
- **5 Body Silhouettes**: Hourglass, Curvy/Pear, Slim/Petite, Plus-Size, and Athletic.
- **5 Rich Skin Tones**: Porcelain Almond, Warm Sand, Caramel Glow, Rich Cocoa, and Deep Bronze.
- **Hairstyles & Headwear**: Knotless Braids, Afro Puff, Sleek Bob, and Silk Hijab/Wrap.
- Real-time scalable vector rendering that morphs cleanly on all screen sizes.

### 2. Dressing Studio
- Interactive garment layering (Modest Dresses, Outerwear Blazers, Handbags, and Shoes).
- Equips garments dynamically onto the avatar.
- **Save to Wardrobe**: Name and save custom outfit creations to your personal profile.

### 3. Modest Fashion Boutique Catalog
- Curated collections organized into 4 core modest categories:
  - **Sunday Best**: Graceful floral midi and maxi dresses with modest necklines.
  - **Corporate Chic**: Tailored double blazers, clean high-neck blouses, and trousers.
  - **Casual Chic**: Tiered pleated skirts and comfortable weekend knitwear.
  - **OWAMBE & Special Occasions**: Luxurious emerald silks, gold lace gowns, and royal wraps.
- Modesty inspection checklists on every piece (neckline, sleeve length, hemline, transparency).

### 4. Interactive Shopping Experience
- Product details modal with size selection (UK 8 to 18).
- Slide-out shopping cart drawer with quantity management and subtotal calculation.
- Demonstration checkout with doorstep delivery form, Paystack/transfer simulation, and style coin discounts.

### 5. Gamification & Daily Challenges
- Themed daily styling challenges (e.g., *"Sunday Best: Pastel Grace"*).
- Instant multi-criteria judging (Modesty, Theme Accordance, Creativity).
- Reward coins balance stored in browser LocalStorage.

## 🚀 How to Run Locally

You can run this project locally with any standard HTTP server:

```bash
# Clone the repository
git clone git@github.com:basit4621/playdress.git
cd playdress

# Run with Python
python3 -m http.server 3000

# Or run with Node npx
npx serve .
```

Open your browser at `http://localhost:3000`.
